# Publication preparation

Based on the original build 57 source archive. Application sources and test files
are unchanged. Publication edits translate console messages in the session helper
and test launcher, and replace Packaging/CITESTE.txt with English README.txt.
No application behavior was changed and the original release archives remain unchanged.

Source-SHA256.json identifies the original build 57 application sources.
The README and contribution/security documents are maintained at repository root.

Personal macOS settings, application runtime data, music libraries, playlists,
sessions, caches and backups are not included in this source preparation.
Tests/fixtures contains audio/image test assets whose provenance and distribution
rights must be verified before public release. Resources/FaderIcon.png requires
the same provenance check. Unicode text in tests is intentional test data.
