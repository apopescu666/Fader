# Fader 1.02 — Build69

- Integrates the validated Fader Lite experience into the production macOS app.
- Transfers the Lite song and added files into Current Queue with one Add / Replace / Cancel dialog.
- Preserves live playback position on confirmed transfer; Cancel retains saved queue and temporary playback.

- Retains the approved 1.01 import scheduling, volume/seek appearance, playlist drop and persistence improvements.
- Uses production identifier/storage and removes test window labels.

Build69 is based on user-validated Test68. This release preparation does not change the audio or search engine.
